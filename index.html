⚡ 1NF Rules

Atomicity
  • 1. Atomic Values Only: Every cell must hold a single value.
    (❌ Avoid: "9123 4567, 9876 5432")
  • 2. No Repeating Columns: Eliminate repeating field groups.
    (❌ Avoid: Elective1, Elective2, Elective3)

🧩 2NF Rules

No Partial Key Dependency
  • 1. Must be in 1NF: Table already meets all First Normal Form criteria.
  • 2. Full Functional Dependency: Every non-key attribute must depend on the entire composite Primary Key (PK).
    (❌ Separate fields that depend on only part of the composite PK)
